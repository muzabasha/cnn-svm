# Reinforcement Learning Virtual Lab

A comprehensive interactive learning environment for understanding Reinforcement Learning concepts.

## Components

### 1. RLTaskSelector
Navigation component for switching between different RL modules.

### 2. RLBasics
- Introduction to RL concepts
- The RL loop (observe, act, reward, update)
- Key components (agent, environment, state, action, reward)
- Interactive chef training example
- Real-world applications

### 3. QLearning
- Q-Learning algorithm explanation
- Interactive Q-table visualization
- Adjustable hyperparameters (α, γ, ε)
- Live training simulation
- Q-value updates in real-time

### 4. PolicyGradient
- Policy gradient methods overview
- Direct policy optimization
- Interactive policy parameter visualization
- Reward history tracking
- Comparison with value-based methods

### 5. ExplorationExploitation
- Multi-armed bandit problem
- ε-greedy strategy demonstration
- Interactive slot machine simulation
- Comparison of exploration strategies
- Visual feedback on learned vs true rewards

### 6. GridWorldSimulator
- Classic grid navigation environment
- Manual control with arrow buttons
- Auto-play with simple AI
- Obstacles, pits, and goal states
- Reward shaping demonstration
- Real-time score tracking

## Features

- 🎮 Interactive simulations
